NEXON 개인 API Key

보스·주간 콘텐츠 자동 확인을 사용하려면 본인의 NEXON Open API Key를 등록해주세요.

로그인한 사용자의 API Key는 서버에서 암호화하여 저장하며, 등록한 Key는 화면에 다시 표시되지 않습니다.

로그인 필요

메기 계정에 로그인하면 본인의 NEXON Open API Key를 안전하게 등록할 수 있습니다.

NEXON 비밀번호를 입력하는 곳이 아닙니다. NEXON Open API에서 발급받은 API Key만 입력해주세요.

API Key 확인 완료

등록된 API Key 원문은 보안을 위해 다시 표시하지 않습니다.
API Key 발급 방법
  1. NEXON Open API에 NEXON ID로 로그인합니다.
  2. 상단 또는 마이페이지에서 내 애플리케이션을 선택합니다.
  3. 애플리케이션 등록을 선택합니다.
  4. 게임에서 메이플스토리를 선택합니다.
  5. 개인 사용·테스트 목적이면 개발 단계로 등록합니다.
  6. 서비스명을 입력하고 약관에 동의한 뒤 등록합니다.
  7. 내 애플리케이션 → 애플리케이션 상세에서 API Key를 확인합니다.
  8. 발급된 API Key를 복사하여 위 입력란에 붙여넣습니다.
  9. API Key 확인 및 등록을 선택합니다.
